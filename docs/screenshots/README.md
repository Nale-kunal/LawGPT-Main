- Use real or realistic demo data (not "Test User" or "Lorem ipsum")
- Capture at 1920x1080 for desktop, 390x844 for mobile
- Include both light and dark mode for key screens
- Save as PNG, optimized (< 500KB per screenshot)
- Name files descriptively: `dashboard-dark.png`, `cases-list-mobile.png`
